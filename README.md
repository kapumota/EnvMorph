### EnvMorph

EnvMorph es un proyecto experimental para estudiar cómo variaciones controladas del entorno afectan el comportamiento observable de workflows Unix y software heredado.

#### Estado actual

El proyecto se encuentra en Fase 0 de migración técnica. F0.2 endurece replay y normaliza la interfaz activa antes de iniciar Git.

El núcleo procede de FlowAttest y conserva capacidades de registro de ejecuciones, manifests, snapshots, comparación, replay, grafos e informes. El literature-pipeline se conserva como primer workload heredado.

Todavía no se implementan portability envelopes, environmental contracts, minimal causal environment ni semantic equivalence.

#### Principio de trabajo

Los resultados experimentales anteriores de FlowAttest no se presentan como evidencia científica de EnvMorph. Toda conclusión futura deberá derivarse de ejecuciones controladas y reproducibles realizadas con la nueva infraestructura.
